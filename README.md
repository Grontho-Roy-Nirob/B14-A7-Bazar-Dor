# 🛒 Bazar Dor — বাজার দর

**Bazar Dor** is a responsive web application that helps users explore daily essential product prices, compare market rates, and track price changes in one place.

## 🌐 Project Links

- **Live Website:** [Bazar-Dor](https://b14-a7-bazar-dor-eosin.vercel.app/)
- **GitHub Repository:** [B14-A7-Bazar-Dor](https://github.com/Grontho-Roy-Nirob/B14-A7-Bazar-Dor)

## ✨ Features

-  View product prices and price changes.
-  Explore products with the highest price increases and decreases.
-  View detailed product information and market-wise prices.
-  Browse products by category.
-  Sort products by price.
-  Sign up and sign in using email/password, Google, or GitHub.
-  View and update profile information.
-  Protect pages that require authentication.
-  Display toast notifications and loading skeletons.
-  Responsive design for mobile, tablet, and desktop.
-  Custom 404 page for unavailable routes.

## 🛠️ Technologies Used

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS, DaisyUI
- **Authentication:** Better Auth
- **UI Libraries:** React Hot Toast, Lucide React
- **Data:** REST API
- **Deployment:** Vercel

## 🔌 API

Bazar Dor retrieves product and category information from the following API:

- **Primary API:** `https://api.api-store.workers.dev/api/bazardor`
- **Alternative API:** `https://api.abcz.workers.dev/api/bazardor`

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Required authentication credentials and environment variables

### Installation

Clone the repository:

```bash
git clone https://github.com/Grontho-Roy-Nirob/B14-A7-Bazar-Dor.git
```

Navigate to the project directory:

```bash
cd B14-A7-Bazar-Dor
```

Install dependencies:

```bash
npm install
```

Configure the required environment variables in a `.env.local` file, then start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
